# 동네한끼 모바일 웹 주문 — 제품 브리프

- 작성: 주문경험팀 PM
- 기준일: 2026년 9월
- 대상 릴리스: 모바일 웹 주문 v3 (가을 첫 주문 캠페인 전 배포)

## 1. 한 줄 소개

동네한끼는 동네 가게 음식을 낮은 수수료로 주문하는 배달 주문 서비스다. 모바일 웹 주문(m.)은 앱을 설치하지 않은 손님이 가게 링크를 눌러 바로 메뉴를 고르고, 옵션 선택 → 장바구니 → 배달 정보·요청사항 → 쿠폰 → 결제 → 주문 현황 확인까지 한 흐름으로 끝내도록 만든 화면이다.

## 2. 사업 맥락

- 가게 수수료는 주문금액의 2%로 대형 배달앱보다 낮다. 서울 마포·서대문·은평을 중심으로 가맹점 약 4,100곳이 있다.
- 일부 자치구와 제휴해 지역화폐(모바일 상품권) 결제를 지원한다. 제휴 조건에 따라 웹 접근성 품질인증(KWCAG 2.2) 획득을 준비하고 있다.
- 주문 유입의 58%가 모바일 웹이다. 가게 인스타그램, 네이버 지도의 가게 정보, 카카오톡 채널에 걸린 '동네한끼로 주문하기' 링크와 가게가 나눠 주는 전단 QR로 들어온다. 첫 방문자 비중이 높아서, 서비스를 모르는 사람도 화면만 보고 끝까지 갈 수 있어야 한다.
- 이번 분기 목표
  - 모바일 웹 주문 전환율(가게 페이지 방문 → 결제 완료): 9.4% → 12%
  - 첫 주문 쿠폰 사용률: 31% → 45%
  - 주문 관련 고객센터 문의: 20% 감소
- 가을 캠페인: 첫 주문 쿠폰 코드 `HANKKI5000`(5,000원 할인, 30,000원 이상 주문 시)을 문자·전단·가게 SNS로 뿌린다. 손님은 받은 코드를 결제 화면에 직접 입력한다.

## 3. 누가, 왜 쓰나

| 고객군 | 주문 비중 | 쓰는 이유 | 특징 |
| --- | --- | --- | --- |
| 20~30대 1인 가구 직장인 | 41% | 퇴근길·야근 뒤 저녁, 야식 | 지하철·버스에서 한 손으로 주문한다. 빨리 끝내고 싶어 하고 쿠폰에 민감하다. |
| 30~40대 맞벌이·육아 가정 | 33% | 주말 저녁 가족 메뉴, 아이 간식 | 아이를 안거나 짐을 든 채 한 손으로 쓴다. 알레르기·맵기 요청을 꼼꼼히 적고, 두 마리 이상 주문이 많다. |
| 50~60대 | 17% (증가 중) | 지역화폐로 결제하려고, 자녀가 가게 링크를 보내 줘서 | 처음 써 보는 사람이 많다. 노안 때문에 글자 크기·화면 크기를 키워 쓰는 경우가 많고, 손이 떨리거나 작은 버튼을 정확히 누르기 어려워하는 분도 있다. |
| 대학생·사회초년생 | 9% | 친구들과 나눠 먹기, 시험 기간 야식 | 쿠폰 코드와 최저가에 민감하다. |

- 스크린리더(TalkBack, VoiceOver)로 주문하는 시각장애 손님, 외부 키보드·스위치로 조작하는 손님의 문의가 한 달에 10건 안팎 꾸준히 들어온다. 공공 제휴 조건과도 맞물려, 이 손님들도 도움 없이 혼자 주문을 끝낼 수 있어야 한다.

## 4. 사용 맥락

- 피크 시간: 평일 18~20시, 금·토 21~24시. 비 오는 날은 주문이 평소의 1.6배.
- 한 손 사용이 기본이다. 지하철 손잡이를 잡고, 아이를 안고, 소파나 침대에 누워서 주문한다. 기기는 6.1~6.8인치 폰이 대부분이다(안드로이드 갤럭시 72%, 아이폰 26%, 기타 2%). 세로 화면으로만 쓴다.
- 이동 중(걸으며 퇴근길), 밝은 야외(현관 앞·놀이터에서 주문 현황 확인), 불 끈 방(야식) 등 환경이 제각각이다.
- 주문 도중 끊김이 잦다. 가족에게 메뉴를 물어보고, 문자함에서 쿠폰 코드를 보고 오고, 아이가 부르면 잠깐 화면을 떠난다.

## 5. 핵심 과업과 예시 데이터

예시 가게: **바삭공방 치킨 망원점** — 평점 4.8(리뷰 2,184개), 최소주문 15,000원, 배달팁 3,000원, 배달 35~50분

### 5.1 메뉴 보기

- 카테고리: 인기 메뉴 · 치킨 · 순살치킨 · 사이드 · 음료 · 소스·추가
- 인기 메뉴: 바삭 후라이드 19,000원 / 달콤 양념치킨 20,000원 / 반반치킨(후라이드+양념) 20,000원 — 가게 대표 메뉴 / 간장마늘치킨 21,000원
- 사이드: 치즈볼 5개 4,500원, 감자튀김 3,500원
- 음료: 콜라 1.25L 2,500원, 사이다 1.25L 2,500원
- 가게 공유하기, 찜하기

### 5.2 옵션 고르기 (예: 반반치킨)

- 부위 선택 (필수, 1개): 뼈 / 순살 +2,000원
- 소스 선택 (필수, 1개): 달콤 양념 / 매운 양념 +500원 / 간장마늘 +1,000원
- 추가 선택 (선택, 최대 3개): 치즈볼 5개 +4,000원 / 콜라 1.25L +2,500원 / 치킨무 추가 +500원 / 머스터드 소스 +300원
- 예: 순살 + 매운 양념 + 콜라 1.25L 추가 → 1개 25,000원 → '담기'

### 5.3 장바구니

- 메뉴별 수량 조절(−/+), 삭제, '메뉴 더 담기'
- 예: 반반치킨(순살·매운 양념·콜라 1.25L) 2개 = 50,000원 → '50,000원 주문하기'

### 5.4 배달 정보와 요청사항

- 저장된 주소: 서울 마포구 망원로 45 망원한강아파트 / 상세주소: 302동 1104호 (새로 고른 주소는 상세주소를 직접 입력)
- 연락처: 010-2345-6789, '안심번호로 주문하기' 기본 선택
- 가게 사장님께 (최대 50자): 예) "땅콩 알레르기가 있어요. 양념에 땅콩가루 빼 주세요" — 알레르기, 맵기 조절, 치킨무 빼기 요청이 가장 많다.
- 일회용 수저·포크 안 받기 (기본 선택)
- 배달 요청사항: 문 앞에 두고 벨 눌러주세요 / 문 앞에 두고 노크해 주세요 / 직접 받을게요 / 도착하면 전화해 주세요

### 5.5 쿠폰 코드

- 문자로 받은 코드를 보고 손으로 옮겨 적는다: `HANKKI5000` (5,000원 할인, 30,000원 이상 주문)
- 현장에서 자주 생기는 상황: 코드 오타(예: `HANKI5000`), 사용 기간 지남, 최소 주문금액 미달

### 5.6 결제

- 결제수단: 동네페이(간편결제, 결제 금액 1% 적립) / 신용·체크카드 / 휴대폰 결제 / 지역화폐(모바일 상품권) / 만나서 결제(카드·현금)
- 결제 금액 예: 주문금액 50,000원 + 배달팁 3,000원 − 쿠폰 5,000원 = 48,000원 → '48,000원 결제하기'

### 5.7 주문 현황

- 진행 단계: 주문 접수 → 조리 중 → 배달 중 → 배달 완료
- 도착까지 남은 시간(예: 약 38분), 주문번호(예: B2K-0928-1147)
- 주문 요약: 메뉴·옵션·수량, 가게 요청사항, 배달 요청사항, 결제수단과 금액
- 조리가 시작된 주문의 취소·변경은 가게와 통화로 처리한다.

## 6. 이번 릴리스에서 지켜야 할 것

- 처음 온 손님이 도움 없이 3분 안에 결제까지 끝낸다.
- 고른 옵션과 요청사항이 그대로 가게에 전달된다.
- 스크린리더·키보드·화면 확대를 쓰는 손님도 혼자 주문을 끝낼 수 있다(KWCAG 2.2 인증 준비).
- 한 손으로 쥔 채로 주요 과업을 끝낼 수 있다.

## 7. 범위

- 포함: 가게 메뉴 → 옵션 → 장바구니 → 배달 정보·쿠폰·결제 → 주문 현황 (배달 주문)
- 제외: 포장·예약 주문, 리뷰 작성, 회원가입(로그인된 기존 세션을 가정), 사장님용 화면
